## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client → manifest/application actions | Untrusted action args choose instance, UUIDs, dry_run, confirm, conflict_policy, reveal |
| Workspace `.coolify/manifest.json` → audit | Local file may be missing, stale, or manually edited |
| Coolify API → MCP compare logic | Live inventory/env data drives findings and suggested writes |
| MCP response → agent | Hints can influence later mutations but must not auto-execute |
