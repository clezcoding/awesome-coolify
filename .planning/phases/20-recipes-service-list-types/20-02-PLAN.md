## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client → recipe inputSchema | Untrusted agent/client crosses here; Zod validates action + per-action fields before any handler runs |
| recipe handler → Coolify API | Only Zod-validated payloads reach outbound HTTPS to createPublicApplication / createService |
| create-one-click → fetchServiceTemplates | Type validated against dynamic CDN fetch — no user-supplied URL reaches ofetch |
| detectBuildPack → local filesystem | repo_path is read via statSync; realpathSync allowlist (mirrors compose_file pattern) prevents path traversal |
