## MCP Icon Contract (`serverInfo.icons`)

Canonical shape after BRND-01. **Data URI first** (D-02 primary signal).

| # | `src` | `mimeType` | `sizes` | `theme` | Notes |
|---|-------|------------|---------|---------|-------|
| 1 | `data:image/png;base64,{MCP_ICON_192_BASE64}` | `image/png` | `["192x192"]` | — | Primary; build-time embed from `mcp-icon-192.png` |
| 2 | `https://cdn.jsdelivr.net/gh/clezcoding/awesome-coolify@main/docs/assets/favicon-32.png` | `image/png` | `["32x32"]` | — | Small CDN entry |
| 3 | `https://cdn.jsdelivr.net/gh/clezcoding/awesome-coolify@main/docs/assets/mcp-icon-192.png` | `image/png` | `["192x192"]` | — | Large CDN entry (Phase 16 URL preserved) |

**Hard rules:**

- **D-01:** ≥1 data URI entry **and** ≥1 CDN PNG entry — never either-only.
- **D-02:** Entry index 0 is always the data URI.
- **PNG only** — no SVG in `icons[]` (spec security note).
- **No runtime `readFileSync` on `docs/assets/`** for data URI — npm tarball excludes `docs/`.
- **`serverInfo.version`:** `readPackageVersion()` → must match `package.json` (`1.0.1` at ship).
- **Unchanged peer fields:** `name: 'awesome-coolify-mcp'`, `title: 'Awesome Coolify'`, `description` verbatim from `package.json`, `websiteUrl: 'https://github.com/clezcoding/awesome-coolify'`.

### Experiment variants (D-03 budget — max 4)

| Variant | Change | Ship if |
|---------|--------|---------|
| V1 (default) | Table above | Baseline candidate |
| V2 | Add `theme: 'dark'` on data URI entry only | V1 UI fails |
| V3 | Swap order — CDN entries before data URI | Client prefers remote fetch |
| V4 | Drop `favicon-32` CDN entry; keep data URI + 192 CDN only | Size-probe negative |

After V4 without Cursor custom icon → **stop**; document client limitation per D-05. Phase passes.

### Icon asset dimensions

| Asset file | Pixel size | `sizes` token | Use |
|------------|------------|---------------|-----|
| `mcp-icon-192.png` | 192×192 | `192x192` | Data URI source + CDN entry |
| `favicon-32.png` | 32×32 | `32x32` | CDN small entry |
| `favicon-512.png` | 512×512 | — | **Do not** embed in data URI (~788 KB) |
