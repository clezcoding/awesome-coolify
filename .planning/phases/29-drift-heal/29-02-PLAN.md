<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client → application.envs:promote | Untrusted args choose source_uuid, target_uuid, dry_run, confirm, conflict_policy, reveal, instance |
| Coolify env API → MCP | Env values may contain secrets and must be masked in responses |
| MCP compare result → target write | Suggestions become mutations only after explicit confirm |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-29-01 | Information Disclosure | envs:promote preview | high | mitigate | Use `maskEnvRecord` and existing reveal policy; tests assert masked values by default |
| T-29-02 | Tampering | envs:promote apply | high | mitigate | `dry_run:true` default; `confirm:true` required on apply; `keep_remote` default; tests assert no writes on failed confirm |
| T-29-03 | Spoofing | wrong-instance or wrong target | high | mitigate | Single routed instance per call; require explicit source_uuid and target_uuid; no cross-instance fan-out |
| T-29-04 | Elevation of Privilege | manifest.audit auto-mutation | high | mitigate | Already mitigated by 29-01 D-06 advisory-only audit; this plan does not modify audit |
| T-29-SC | Tampering | npm installs | low | accept | No new packages |
</threat_model>
