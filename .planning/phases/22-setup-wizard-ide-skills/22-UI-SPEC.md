## Spacing Scale

Declared values (multiples of 4; align with `shared.css` custom properties):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Eyebrow dot gap, inline icon gaps |
| sm | 8px | `--space-2`; badge row, btn-row gaps |
| md | 16px | `--space-4`; default card padding unit, form field margin-bottom |
| lg | 24px | `--space-6`; section internal gaps, card padding (`--space-6` in `.card`) |
| xl | 32px | `--space-8`; nav-bar margin, output-section margin-top |
| 2xl | 48px | `--space-12`; container vertical padding |
| 3xl | 64px | `--space-16`; page bottom padding, hero breathing room |

Exceptions:

- Touch/copy targets: buttons and client-grid links ≥ 44px height (padding `0.7rem 1.2rem` on `.btn` satisfies this).
- Monospace command rows in `pre`: vertical padding `16px` (`--space-4`).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#050505` (`--bg-primary`) + grid/noise overlays | Page background, body |
| Secondary (30%) | `rgba(255,255,255,0.03–0.05)` glass + `#0a0a0a` elevated | Cards, forms, `pre` blocks, client grid |

| Destructive | `#ef4444` (new token `--destructive` if needed) | Destructive actions only — **none in Phase 22 setup** |
| Success / info | `#22c55e` (`--success`), gold `#fcd34d` (`--gold`) | Security notices, eyebrow, nav hover |

**60/30/10 rule:** Hero mesh image is decorative (one flourish max); all form/setup content sits on calm glass panels without additional shaders or wave animations on the same page.

## Motion & Interaction

CSS-first; durations ≤ 300ms for UI; `prefers-reduced-motion` already in `shared.css` — preserve and extend.

| Element | Properties | Duration | Easing | Notes |
|---------|------------|----------|--------|-------|
| Input focus | `border-color`, `box-shadow` | 200ms | ease-out | Match existing `input:focus`; never `transition: all` |
| Primary button hover | `background-color`, `transform`, `box-shadow` | 300ms | `cubic-bezier(0.34, 1.56, 0.64, 1)` | Existing `.btn`; add `:active { transform: scale(0.97) }` |
| Secondary button | `border-color`, `background-color` | 200ms | ease-out | No scale on hover for secondary |
| Copy button feedback | `background-color`, `border-color` | 0ms text swap; 160ms | ease-out on bg | Instant label change ("Copied"); optional brief success border |
| Output section reveal | `opacity`, `transform: translateY(8px)` | 250ms | `cubic-bezier(0.23, 1, 0.32, 1)` | On `[hidden]` removal; start `opacity:0; translateY(8px)` — **never** `scale(0)` |
| Card hover (docs only) | `transform`, `box-shadow`, `border-color` | 350ms | spring-ish cubic | Existing `.card:hover`; disable transform on `@media (prefers-reduced-motion: reduce)` |
| Step progress (setup docs) | `width` or `opacity` on indicator | 200ms | ease-out | Occasional-use wizard docs — standard animation OK |
| Eyebrow pulse | `opacity` | 2s | ease-in-out | Existing `pulse-glow`; reduced-motion overrides to 0.01ms |

Popover/tooltip: if added for copy hints, `transform-origin` at trigger edge; 125–200ms ease-out; `scale(0.97)` + opacity from `scale(0.95)` entry — not `scale(0)`.

## Agent-Visible UX Contract (MCP `setup` tool)

Clarity over decoration. Structured fields drive agent UI; `_formattedText` is the human-readable banner.

### Success / in-progress response shape

```json
{
  "ok": true,
  "data": {
    "setup_status": "in_progress" | "complete",
    "mode": "greenfield" | "link-existing",
    "current_step": "gh_preflight" | "repo" | "linkage" | "recipe" | "manifest" | "domains" | "env" | "deploy_watch",
    "steps_completed": ["gh_preflight", "linkage"],
    "steps_remaining": ["recipe", "manifest"],
    "manifest_path": ".coolify/manifest.json",
    "deployment_uuid": "<optional when deploy_and_watch>"
  },
  "_formattedText": "…",
  "_meta": { "truncated": false, "chars": N, "max_chars": 8000 }
}
```

### Soft-pause response shape (`needs_human`)

Use `ok: false` with dedicated code OR `ok: true` with `setup_status: "paused"` — **pick one in implementation; contract prefers:**

```json
{
  "ok": false,
  "error": {
    "code": "COOLIFY_SETUP_PAUSED",
    "message": "GitHub CLI is not authenticated.",
    "recoveryHints": [
      "Install GitHub CLI: https://cli.github.com/ (or brew install gh)",
      "Run: gh auth login",
      "Re-call: setup({ action: \"resume\" }) after auth succeeds"
    ],
    "data": {
      "pause_reason": "gh_unauthenticated" | "gh_missing",
      "resume_action": "resume",
      "resume_params": {}
    }
  },
  "_formattedText": "…"
}
```

**Never** poll-wait inside the tool (D-06). No spinner semantics in MCP — pause is immediate.

### `_formattedText` banner templates (exact copy)

**Paused — gh missing:**

```
⏸ SETUP PAUSED — GitHub CLI not found

Human action required:
1. Install gh: https://cli.github.com/
2. Run: gh auth login
3. Re-call: setup({ action: "resume" })
```

**Paused — gh unauthenticated:**

```
⏸ SETUP PAUSED — GitHub CLI not authenticated

Human action required:
1. Run: gh auth login
2. Re-call: setup({ action: "resume" })
```

**In progress (example):**

```
▶ SETUP IN PROGRESS — greenfield · step: linkage

Completed: gh_preflight
Next: recipe → manifest

Optional (off by default): include_domains, set_env, deploy_and_watch
```

**Complete:**

```
✓ SETUP COMPLETE

Manifest: .coolify/manifest.json
Mode: link-existing | greenfield

Suggested: git push (manual — never auto-pushed)
```

**Deploy watch timeout (when flag enabled):**

```
⚠ DEPLOY WATCH TIMED OUT

deployment_uuid: <uuid>
Status: in_progress (or last known)

Recovery:
• deployment({ action: "get", deployment_uuid: "<uuid>" })
• deployment({ action: "watch", deployment_uuid: "<uuid>", timeout: 300 })
```

Use Unicode symbols sparingly; agents parse `recoveryHints` first. `_formattedText` mirrors hints for humans.

### Step progress semantics

| Step key | Display label | Shown when |
|----------|---------------|------------|
| `gh_preflight` | GitHub CLI preflight | Always first |
| `repo` | GitHub repo (greenfield) | `mode: greenfield` |
| `linkage` | Coolify project / env / server | Both modes |
| `recipe` | App from recipe | Greenfield core |
| `manifest` | Write manifest | Both modes |
| `domains` | Domains | `include_domains: true` |
| `env` | Environment vars | `set_env: true` |
| `deploy_watch` | Deploy + watch | `deploy_and_watch: true` |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (install.html MCP) | **Generate config** (existing — do not change) |
| Primary CTA (skills block) | **Copy install command** |
| Skills install command (canonical) | `npx skills add clezcoding/awesome-coolify -a cursor -a claude-code -a codex` |
| Skills install alt | `npx skills add clezcoding/awesome-coolify --all` (document as optional in hint) |
| Setup docs CTA | **Open setup guide** (links `docs/en/setup.md`) |
| Empty state heading (no MCP config yet) | **Install the MCP server first** |
| Empty state body | Point to `install.html` or deeplink; skills require MCP + Coolify credentials before workflows run. |
| Error state (docs JS / clipboard) | **Could not copy** — Select the command and copy manually. |
| Error state (setup tool generic) | Problem in `error.message` + numbered `recoveryHints` (no generic "Something went wrong") |
| Soft-pause heading | **SETUP PAUSED** — `{reason}` (see banner templates) |
| Destructive confirmation | None in Phase 22 (recipe create has no confirm per established pattern) |
| README skills section title (EN) | **IDE skills (Cursor, Claude Code, Codex)** |
| README setup pointer | After MCP install, run `setup({ action: "preflight" })` or see [Setup guide](docs/en/setup.md) |

**README / docs consistency:** Same command strings everywhere — no divergent repo slug or agent flag spelling. DE README mirrors EN structure; commands stay English.
